# SaveTo

A simple Vencord plugin for quickly saving images to anywhere on your computer.

![Preview](https://i.postimg.cc/8CmxCdgB/Discord-Canary-H5Po-YU1Iq6.png)

## Supports

- Image/video/file attachments
- (Most) embedded images
- User avatars, including server-specific avatars
- Server icons and banners
- Stickers
- Emotes

## Installation

Follow the [Vencord documentation for installing custom plugins](https://docs.vencord.dev/installing/custom-plugins/).
